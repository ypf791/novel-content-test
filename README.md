# novel-content-test

Private publication-content repository for the novel-reader proof of concept.

- `main`: production publication copies only.
- `develop`: invited-reader preview copies.
- `published/`: the only content source included in the reader build.
- `site/`: private submodule pointing to `ypf791/novel-reader-web`.

The POC must never read directly from Novel Wiki. Content arrives here only as
an explicitly selected publication copy.
